## Production prompt

```text
Create a 1200×675 evaluation loop titled “How to Tell If It Actually Works”. Subtitle: “Turn a promising demo into repeatable evidence.”

Loop:
1. “Define the task”
2. “Create representative cases”
3. “Write pass/fail checks”
4. “Run the same cases”
5. “Inspect failures”
6. “Change one thing”
7. “Repeat”

Scorecard:
“Correct?”
“Complete?”
“Uses the right sources?”
“Safe to act on?”
“Works again?”

Note: “Use automated checks where possible and human judgement where needed.”

Comparison:
“DEMO” — “Can it work once?”
“EVAL” — “Does it work reliably on the cases that matter?”

Include no score, pass rate, benchmark, or claim that every quality is binary.
```

## Accessibility text

**Alt text:** A seven-step loop defines a task, creates representative cases and pass/fail checks, runs the same cases, inspects failures, changes one thing, and repeats. A scorecard asks whether each result is correct, complete, sourced, safe to act on, and repeatable. A strip contrasts a one-time demo with a repeatable eval.

**Caption:** Evals turn a promising demo into repeatable evidence on the cases that matter.
