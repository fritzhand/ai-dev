## Accessibility text

**Alt text:** Local Git history is connected by a right-pointing push arrow and a left-pointing clone-or-pull arrow to a repository hosted on GitHub. Git records commits and branches on a computer; GitHub hosts a remote copy for sharing, review, and automation. A warning says to rotate a secret if it reaches history.

**Caption:** Git records local history; GitHub can host and share a remote copy.
